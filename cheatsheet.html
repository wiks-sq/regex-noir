    FlagNameEffect
    gglobalFind every match instead of stopping at the first. Almost every case needs it.
    iignore casea also matches A. Easy to over-match with.
    mmultiline^ and $ match at the start and end of every line.
    sdotAll. also matches newlines.

    10Common Traps

    Read before submitting
    Greedy runs too far

    ".*" grabs from the first quote to the last one. Use ".*?" or "[^"]*".

    ^ only matched once

    Without the m flag, ^ and $ mean the whole text, not each line.

    The unescaped dot

    10.0 also matches 1000. Write \. for a real dot.

    The i flag lets in decoys

    Case-insensitive matching widens every letter in the pattern. Only use it when the case calls for it.

    Underscore is a word character

    \bSIG\b doesn't match inside SIG_DEBUG, because _ counts as part of the word.

    Empty matches

    \d* matches the empty string at every position. Use + when you need at least one.

    Alternation splits everything

    ^GET|POST / means ^GET or POST /. Group it: ^(GET|POST) /.

    Nested quantifiers

    Patterns like (a+)+$ can take exponential time on near-misses. Keep repeats unambiguous.

    Which group is evidence?

    Some cases grade capture group 1. Wrap helper groups in (?:…) so they don't take the first number.
